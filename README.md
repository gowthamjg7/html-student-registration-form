# Student Registration Form

A beginner-friendly student registration form built using **HTML5**.

## About the Project

This project is my second HTML practice assignment as part of my Python Full Stack Development learning journey.

It demonstrates the use of HTML forms, input types, form validation, semantic elements, and tables.

## Technologies Used

- HTML5
- Semantic HTML
- HTML Forms
- HTML Tables

## Features

- Student name, email and password fields
- Gender selection using radio buttons
- Multiple skill selection using checkboxes
- Date of birth input
- Required field validation
- Student records displayed in an HTML table
